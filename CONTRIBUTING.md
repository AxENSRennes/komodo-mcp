# Contributing

Issues and pull requests are welcome.

## Development setup

1. Install Node.js 20 or newer.
2. Run `npm ci`.
3. Run `npm run check` before submitting a change.
4. Run `npm run build` and commit any intended catalog changes.

Do not commit API keys, secrets, local `.env` files, or responses containing
private Komodo configuration. Add tests for behavioral changes and keep the
six-tool public surface compact unless a new native capability cannot be
represented through it.
